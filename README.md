# Leave Management API

A Spring Boot REST API for submitting and managing employee leave requests. This project follows a layered architecture and uses a thread-safe in-memory repository, so no database is required.

## Technology
- Java 17
- Spring Boot 3.2.11
- Gradle
- Spring Web and Jakarta Bean Validation
- Lombok
- JUnit 5, Mockito, and MockMvc

## Build and run
Requires JDK 17 and a local Gradle installation (the supplied template ZIP did not contain Gradle wrapper scripts). You can also import the folder into IntelliJ IDEA and run Gradle tasks from its Gradle tool window.

```bash
gradle clean build
gradle bootRun
```

The default profile is `dev`. To run with another profile:
```bash
gradle bootRun --args='--spring.profiles.active=prod'
```

The server runs at `http://localhost:8080`.

## API endpoints

| Method | Endpoint | Description | Success |
|---|---|---|---|
| GET | `/leaves` | List all leave requests | 200 OK |
| GET | `/leaves/{id}` | Retrieve a request by ID | 200 OK |
| POST | `/leaves` | Submit a new leave request | 201 Created |
| PUT | `/leaves/{id}` | Replace an existing leave request | 200 OK |
| DELETE | `/leaves/{id}` | Delete a request | 204 No Content |

### Leave request fields
- `id`: generated by the server
- `employeeId`: required employee identifier
- `leaveType`: required string, e.g. `ANNUAL`, `SICK`, `PERSONAL`
- `startDate`, `endDate`: required ISO dates (`YYYY-MM-DD`); end date cannot be before start date
- `reason`: required, up to 500 characters
- `status`: starts as `PENDING` on create; can be set during update (e.g. `APPROVED`, `REJECTED`)

### Example: create a leave request
```bash
curl -i -X POST http://localhost:8080/leaves \
  -H 'Content-Type: application/json' \
  -d '{
    "employeeId": "EMP-1001",
    "leaveType": "ANNUAL",
    "startDate": "2026-11-02",
    "endDate": "2026-11-04",
    "reason": "Family vacation"
  }'
```

Example response (`201 Created`):
```json
{
  "id": 1,
  "employeeId": "EMP-1001",
  "leaveType": "ANNUAL",
  "startDate": "2026-11-02",
  "endDate": "2026-11-04",
  "reason": "Family vacation",
  "status": "PENDING"
}
```

### Example: update a leave request
```bash
curl -i -X PUT http://localhost:8080/leaves/1 \
  -H 'Content-Type: application/json' \
  -d '{
    "employeeId": "EMP-1001",
    "leaveType": "ANNUAL",
    "startDate": "2026-11-02",
    "endDate": "2026-11-04",
    "reason": "Family vacation",
    "status": "APPROVED"
  }'
```

## Error handling
Errors are returned as JSON. A missing ID returns `404 Not Found`; invalid fields or an end date before the start date return `400 Bad Request`.

Validation error example:
```json
{
  "timestamp": "2026-10-13T10:00:00",
  "status": 400,
  "error": "Bad Request",
  "message": "Validation failed for request parameters",
  "path": "/leaves",
  "validationErrors": {
    "employeeId": "Employee ID is required"
  }
}
```
